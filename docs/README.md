# Interactive Visualizations

This directory contains interactive visualizations and demonstrations for the Terraform GenAI RAG project.

## Contents

### Syvaq Miracle Cache Synthesis

An advanced interactive visualization demonstrating a neural cache optimization system with real-time monitoring and control capabilities.

**Features:**
- Real-time performance metrics (cache efficiency, synthesis rate, active nodes)
- Interactive neural network topology visualization
- System control panel (start/stop, optimize, reset)
- Live activity logs
- Performance statistics dashboard
- Fully responsive design

**Technology Stack:**
- React 18 (via CDN)
- Vanilla JavaScript
- CSS3 with animations and gradients
- Self-contained HTML file (no build process required)

## Accessing the Visualizations

### Local Access

1. Clone the repository
2. Navigate to the `docs` directory
3. Open `index.html` in your web browser
4. Or directly open `Syvaq_Miracle_Cache_Synthesis.html`

### GitHub Pages

If GitHub Pages is enabled for this repository, the visualizations can be accessed at:

```
https://theavcfiles.github.io/terraform-genai-rag/
```

Direct link to Syvaq visualization:
```
https://theavcfiles.github.io/terraform-genai-rag/Syvaq_Miracle_Cache_Synthesis.html
```

## Enabling GitHub Pages

To enable GitHub Pages for this repository:

1. Go to repository **Settings**
2. Navigate to **Pages** section (under "Code and automation")
3. Under **Source**, select the branch (e.g., `main`)
4. Set the folder to `/docs`
5. Click **Save**
6. Wait a few minutes for deployment
7. Access your site at the provided URL

## Technical Details

All visualizations are self-contained HTML files with embedded:
- React components (using Babel standalone for JSX)
- CSS styling with animations

No build process or external dependencies are required beyond the CDN-loaded libraries.
